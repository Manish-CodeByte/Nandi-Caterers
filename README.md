# Nandi Caterers — Luxury Indian Catering Landing Page

A production-grade, ultra-premium editorial landing page for **Nandi Caterers**, Mangalore & surrounding regions. Engineered with Next.js 14, Tailwind CSS, Framer Motion, and Lucide React.

## 🌟 Features

- **Mobile-First Luxury Architecture:** Fully responsive across all devices (320px to 4K displays).
- **Zero-Friction Direct Lead Generation:** Instant WhatsApp and Direct Phone Calling triggers without slow forms or sign-up barriers.
- **Brand Palette (70/20/10):**
  - **70% Warm Ivory (#FAF7F0) & Soft Cream (#F3EDE2)**
  - **20% Burgundy (#641C2D, #42121E)**
  - **10% Champagne Gold (#B89A5A)**
- **Sacred Nandi Bull Emblem:** Custom vector SVG identity with gold gradient flourishes.
- **Editorial 4x2 Gallery Grid:** Symmetrical card presentation with full-screen Lightbox and pre-filled WhatsApp enquiry routing.
- **SEO & Structured Data:** OpenGraph, Twitter Cards, Canonical tags, and JSON-LD LocalBusiness Schema.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

`ash
# Clone the repository
git clone https://github.com/Manish-CodeByte/Nandi-Caterers.git
cd Nandi-Caterers

# Install dependencies
npm install

# Start development server
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) to view the live site.

### Production Build

`ash
npm run build
npm run start
`
